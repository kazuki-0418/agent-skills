【意図】Replit Slides 風の単ファイル horizontal-swipe deck, テーマ 1 セットを選び混ぜない。
【レイアウト】
- Pick one theme: helix / holm / vance / bevel / world-dark / world-mint / atlas / bluehouse
- Cover + agenda + content N + 締め (N は【ユーザーの素材】の長さが決める, 各要点を完全にカバー; 短い素材は 6-10 から。長い素材は枚数を増やす)
【デザインの要点】
- 各テーマに完全なパレット + フォント + accent がある, 混ぜない
