【レイアウト】
- Rotating type ring (SVG + transform)
- Animated globe / 抽象ジオメトリ
- Ticking timer (mono フォント, JS はあってもなくても)
- Parallax labels が浮かぶ
【デザインの要点】
- 純 CSS モーション。滑らかにループ
- 映画的な調色 + neon accent 1 つ
