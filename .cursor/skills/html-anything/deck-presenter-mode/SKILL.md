【テンプレート: Presenter Mode Deck】
【意図】台詞を忘れるのが怖いスピーカー専用 deck, 逐語 notes と popup teleprompter を含む。
【レイアウト】
- 各ページ + `<aside class="notes">` 150-300 字の原稿
- 右下の小さな toolbar: T でテーマ切替 / S で popup を開く
- Popup: CURRENT / NEXT / SCRIPT / TIMER のマグネットカード 4 枚
【デザインの要点】
- 既定 tokyo-night; テーマ 5 セット (light を含む)
