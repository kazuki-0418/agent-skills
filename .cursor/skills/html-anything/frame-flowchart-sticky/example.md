# 新規ユーザーの始め方 · HTML Anything

> ホワイトボード風の付箋フローチャート, ノード6, 分岐1

## フロー
1. **localhost:3456 を開く** — ブラウザでメイン画面へ
2. **ローカル agent を自動検出** — PATH をスキャンし, ログイン済み CLI を列挙
3. **テンプレートを選ぶ** — 75個のテンプレートをシーン別に分類
4. **内容を貼る / ファイルを上げる** — Markdown / CSV / Excel に対応
5. **⌘+Enter で変換** — agent をストリーム呼び出し → SSE → プレビューをリアルタイム更新
6. **ワンクリックでコピー / ダウンロード** — WeChat公式 / Twitter / 知乎 / PNG / HTML

分岐: ローカル agent がなければ → インストールへ誘導 (Claude / Cursor / Codex)
