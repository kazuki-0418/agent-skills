# knowledge/

分野ごとの**事実・決定・学習メモ**を置く場所。手順は置かない。

| 置きたいもの | 置く場所 | 置かない場所 |
|---|---|---|
| 手順（どうやるか） | `.cursor/skills/` | ここ |
| 短い禁止・境界 | Bot Description / Team rules | ここ（長くしない） |
| 事実・決定・「前回こうだった」 | ここ、または Obsidian | Grok Bot Memory（正本にしない） |
| 好み・口調・いつ ping するか | Grok Bot Memory | ここ（手順や数値を Memory に落とさない） |

Grok Bot に「Knowledge」という専用機能はない。知識を吸収させるなら、このフォルダを Read させるか、Bot Description に1行ポインタを書く。

ファイルを足すときは、1トピック1ファイル。日付と「まだ仮説」か「決定」かを先頭に書く。
