# AI 編集を使いやすくする 5 つの小さな習慣

## カバー
保存推奨 · AI ツール勢 必見

## カード 1: 完璧な prompt を捨てる
書いた prompt が一度で完璧なことはない。それを**対話**と思え, SQL ではない。

## カード 2: AI にあなたの書式を見せる
markdown / CSV を貼る前に, 先に伝える"X スタイルで出してほしい"——
具体的な参照 1 つは, 形容詞 50 個より効く。

## カード 3: テンプレートを使え, 毎回書き直すな
使えるプロンプトはテンプレートにしろ。HTML Anything はテンプレートを選ぶだけ,
世界級のデザイン system が 9 セットすぐ使える。

## カード 4: 二次編集は diff を走らせる
再生成は 0 からではない。内容を直したら diff だけ送り, AI に既存 HTML 上で微調整させる,
token を 80% 節約 + デザインスタイルは維持。

## カード 5: ローカル session を再利用する
API Key は不要, ローカルの Claude / Cursor / Codex を走らせる。限界費用 0,
速度はリモート API よりずっと速い。

## まとめ
ツールは多いほど良いのではない, 流れが滑らかこそ本当に使いやすい。
フォローして, 毎週 AI workflow 実戦を更新する。
