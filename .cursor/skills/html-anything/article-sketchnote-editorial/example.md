# 創発の命名

**Topic / 領域**：複雑系 · 1972
**English Category**：COMPLEX SYSTEMS / SCIENCE

## 弧線

| 駅 | 内容 |
|---|---|
| 01 起点 | 20 世紀中葉、物理学者は信じていた「粒子を一粒ずつ語り切れば、全体も語り切れる」 |
| 02 失敗一 | **還元論**：原子層まで分けて一つずつ説明する、結論：どの原子も「賢く」ない |
| 03 失敗二 | **加算**：個体の行動を足す、結論：体重は足せる、意識は足せない |
| 04 転換 | **全体——** 全体は個体の和ではない |
| 05 頓悟 | ある臨界点で、全体の新しい性質が突然現れ、単一の個体にはこの面は見えない |
| 06 命名 | **創発 / Emergence** — Phil Anderson, 1972, "More Is Different" |

## ネタバレしないタイトル（feature 用）

「アリを一匹ずつ見ても、アリの群れは語れない」

## 詩的な余韻（epilogue）

「こうして、全体は自分の目を生やした。」
