【テンプレート: ミニマル方向キー Keynote】
【意図】「言うことはあるが、見るものはほとんどない」ミニマル keynote。
【レイアウト】
- ページ数は【ユーザーの素材】が決める (短い素材は 8 ページから。長い素材は枚数を増やす); 各ページは単色背景, 次のパレットから循環して選ぶ (藍 / ミルク / 絳 / 翠 / 灰 / 紫 / 白 / 炭), 同色は再利用可
- 160px display タイトル + 4px 短く太い accent 線
- 矢印 → 接頭の Mono リスト
- 左下 ← → kbd ヒント + 右下ページ番号
