【テンプレート: 雑誌風ポスター / Magazine Poster】
【意図】Newsprint editorial スタイルの縦長ポスター。新聞の全ページのように読める。
【レイアウト】
- Dateline トップバー (publication / date / issue)
- Oversized serif headline (strike-through 語 + 斜体 accent を含む)
- 2 カラム body 本文
- 番号付き sections 6。各々に小見出し + 1-2 段落 + pull-quote
- 下部クレジット + 小さな ornament
【デザインの要点】
- 紙感: 暖灰 cream 背景 + 細い dot pattern, 黒い文字
- フォント: Playfair Display + IBM Plex Serif + JetBrains Mono
